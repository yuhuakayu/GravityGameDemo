仕样书：关掉旋转限度 + 游戏开始时的转场

====================================
一、关掉旋转限度
====================================

WorldRoot.cs 里的 limitSteeringRange（方向盘范围限制，现在是左右各 360°）改成不限制：
1. 默认值改成 false。
2. 所有场景和预制体里已经保存为 true 的地方也改成 false（Stage1、Maze_01～05 等所有用到 WorldRotator 的场景）。
3. 开关和 steeringRange 保留在 Inspector，代码逻辑不用删。
4. 手柄陀螺仪、摇杆、键盘都要能一直转下去，转超过 360° 也不会卡住或者反转。

====================================
二、游戏开始时也用转场
====================================

现在只有选关进入关卡时有 SceneTransition 的圆形转场。改成：
1. 游戏启动、第一个场景（主菜单）出现时，播放一次转场的"打开"动画（从全黑圆形打开），时长用 openDuration。
2. 主菜单里如果有不经过 SceneTransition 直接切场景的地方（例如开始游戏、继续游戏），也改成用 SceneTransition.LoadScene。
3. 开场这一次不播放转场音效。
4. 转场动画进行时不接受菜单输入。

====================================
三、验证和汇报（只做这些）
====================================

编译无错误；Stage1 连续往一个方向转 3 圈以上不会被挡住；启动游戏能看到开场转场。
汇报 3 行左右，不写报告文件。
