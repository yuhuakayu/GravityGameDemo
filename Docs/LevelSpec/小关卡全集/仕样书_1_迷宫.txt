====================================
二、门装在哪一面（现在的代码只认 D，要补上）
====================================

D = 门在地上，U = 门在天花板上倒挂（上面那格是 #），[ = 门在左墙上，] = 门在右墙上。
1. BuildScene 里这 4 个字母都调用 PlaceDoor(door, center, cell)。
2. PlaceDoor 先设旋转：door.transform.localRotation = Quaternion.Euler(0, 0, z)，z：D 为 0，U 为 180，[ 为 -90，] 为 90。
   再用原来的算法求门图底边中点（旋转以后的位置），对齐到 center + (Vector2)(Quaternion.Euler(0, 0, z) * Vector2.down)。D 的结果和原来一样。
3. 用到的：Maze_01～03、05、07 是 D；04、06 是 ]；08 是 U。

====================================
三、激光的开关周期（每道单独设）
====================================

1. LaserEmitter 加：
     public void SetCycle(float on, float off) { onDuration = Mathf.Max(0.01f, on); offDuration = Mathf.Max(0f, off); }
     public Vector2 BeamStart => transform.TransformPoint(muzzleOffset);
     public Vector2 BeamEnd => BeamStart + (Vector2)transform.right * BeamLength;
2. MazeSceneBuilder 生成激光后按下表调用 SetCycle，再调用 PrefabUtility.RecordPrefabInstancePropertyModifications(emitter)。
   坐标是（列, 行），从地图左上角 0 开始数。表里没有的激光（包括老 Maze_03 的两道）保持一直亮。
     Maze_06：(4,2) 亮 1.3 秒、灭 1.7 秒；(6,6) 亮 1 秒、灭 1.8 秒
     Maze_07：(4,8) (8,7) (7,1) (1,2) 都是亮 1 秒、灭 1.6 秒
     Maze_08：(7,2) 亮 2.3 秒、灭 1.6 秒
3. 周期从正式开始游戏算起，一开始都是亮的，死了重开从头算（现有逻辑就是这样，不用改）。
4. 发射器的位置是故意摆的：发射器是实心小块，都放在玩家不会贴着滑过去的那一面。Maze_07 的 4 个发射器贴在尖刺块那一面，照常生成就行。

====================================
四、迷宫的擦边判定
====================================

新组件 MazeNearMiss（生成器给 8 个迷宫场景都加上），玩家 IsGameplayActive 时每个 FixedUpdate 检查一次，触发调用 NearMissFeedback.NearMiss（冷却 1.4 秒）。
玩家的两个圆、半径 PR = 0.4 见仕样书_0 第三节第 6 条。下面的距离都是格（Unity 单位），不是地图格（地图一个字符 = 2×2 格）。
"快"= 玩家竖直速度（屏幕方向）的绝对值 > 2.5，或者世界正在转（WorldRotator.IsRotating）。
1. 尖刺 kind "spike"：每个尖刺格（Spikes_ 物体，2×2 的 BoxCollider2D），圆心到这个格子的距离（在格子本地坐标里算点到矩形的距离）< PR + 0.55，并且"快"。
2. 激光 kind "laser"，两种情况：
   亮着时：圆心到光束线段（BeamStart～BeamEnd）的距离 < PR + 0.5，并且"快"；
   刚冲过去它就在身后亮起：激光灭着的时候玩家碰到过光束那条线（距离 < PR + 0.04，记下时间），之后 0.45 秒内这道激光从灭变亮。
   亮灭用 LaserEmitter.IsBeamActive；灭着时 BeamLength 也照算，所以线段一直拿得到。
3. 死亡判定不变（尖刺和激光现有的触发器）。
