云海坠落

天空 · 4 个小关

动作向关卡原型 · 一关一个机关，每关 3 到 5 拍、几秒钟

演示会自动打完这一关：画面上方写着每一拍该怎么转，右下角的方向盘是手柄输入、左边是当前角度，擦身而过时会慢动作。

用时 0.0 秒 死亡 0
调参（改了会从这一关开头重来）

四关各自的爽点

  1. 3-1 跷跷板：一站上去就翻，把你倒进半空；转世界拐弯，落到下一块上它又翻。
  2. 3-2 气球雷：横着往下掉的时候来回拧，气球也跟着摆，要从缝里钻过去。
  3. 3-3 散云：云只托你 1 秒，散之前转走，还要从两排刺中间的缝里穿过去。
  4. 3-4 气球平台：被带着往上飘，刺破前转身飞向门，边飞边微调把门转正。

操作

  • ← Q 逆时针，→ E 顺时针，R 这一关重来
  • 手柄：摇杆横向或 L2 / R2，Options 重来
  • 在空中转世界就是在拐弯：你永远往屏幕下方掉。

和游戏一致的规则

  • 玩家照 PlayerController：横向速度每步清零，只往屏幕下方掉；在空中时世界绕你 0.16 秒前的位置转；门转正（20° 以内）才开。
  • 镜头大致对着整关，稍微跟着玩家；演示用 180°/s（游戏里现在是 135°/s，可以在调参里改）。下落速度上限 11 格/秒。
  • 跷跷板、气球雷、会散的云、气球平台是这个原型新加的，游戏里还没有。
