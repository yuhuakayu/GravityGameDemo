矿坑 · 4 个小关

动作向关卡原型 · 一关一个机关，每关 4 到 6 拍、几秒钟

演示会自动打完这一关：画面上方写着每一拍该怎么转，右下角的方向盘是手柄输入，遇到险情会慢动作。

用时 0.0 秒 死亡 0
调参（改了会从这一关开头重来）

四关各自的爽点

  1. 1-1 落石：你一转，石头也跟着滚；落地要马上再转，它们会砸在你刚站过的地方。
  2. 1-2 塌方：一转身后就开始塌，右、下、左、下、右、下一口气转完。
  3. 1-3 矿车：吊斗矿车越跑越快，弯道前连续大翻 180°，最后撞车飞出去。
  4. 1-4 木板：往竖井里一掉，头顶的木板就松了；落地马上转走。

操作

  • ← Q 逆时针，→ E 顺时针，R 这一关重来
  • 手柄：摇杆横向或 L2 / R2，Options 重来
  • 演示中按任意方向键就接手自己玩；画面上方一直提示下一拍。

和游戏一致的规则

  • 玩家照 PlayerController：横向速度每步清零，只往屏幕下方掉；门转正（20° 以内）才开。
  • 镜头大致对着整关，稍微跟着玩家；演示用 180°/s（游戏里现在是 135°/s，可以在调参里改）。
  • 落石、塌方、吊斗矿车、木板是这个原型新加的，游戏里还没有。
