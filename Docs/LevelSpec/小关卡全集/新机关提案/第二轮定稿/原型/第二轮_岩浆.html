岩浆 · 第二轮 7 关

动作向关卡原型 · 一关一个岩浆机关，每关 3 到 5 拍、几秒钟

演示会自动打完这一关：画面上方写着每一拍该怎么转，右下角的方向盘是手柄输入、左边是当前角度，岩浆擦身而过时会慢动作。

用时 0.0 秒 死亡 0
调参（改了会从这一关开头重来）

四关各自的爽点

  1. 2-1 封口：一转，池底的岩浆就顺着墙爬向出口，要抢在它封口前钻出去。
  2. 2-2 追击：你一走，冷却的岩浆就活了，跟着你一路往下流；它比你慢，但你一停它就追上来。
  3. 2-3 晃开：出口那边会被岩浆封住，先斜 45° 把岩浆晃到另一头，再猛打方向冲过去。
  4. 2-4 冲门：岩浆从头顶灌下来，落到底马上转，门一转正就冲进去。

操作

  • ← Q 逆时针，→ E 顺时针，R 这一关重来
  • 手柄：摇杆横向或 L2 / R2，Options 重来
  • 可以试试 2-3 不晃、直接往左冲：岩浆会先一步封住出口。

和游戏一致的规则

  • 玩家照 PlayerController：横向速度每步清零，只往屏幕下方掉；45° 的地面会"粘住"玩家；门转正（20° 以内）才开。
  • 镜头大致对着整关，稍微跟着玩家；演示用 180°/s（游戏里现在是 135°/s，可以在调参里改）。
  • 岩浆是粒子流体，永远往屏幕下方流，比玩家下落慢；暗红色的是冷却的岩浆，你一动它才"活"过来。岩浆是这个原型新加的，游戏里还没有。
