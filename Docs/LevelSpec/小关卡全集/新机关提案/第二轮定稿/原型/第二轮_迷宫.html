五关各自的爽点

  • 01 之字：右、回正、左、回正、右、回正，转晚一点就擦着尖刺掉进洞；最后把横着的门转正。
  • 02 甩尾：竖井里越掉越快，快到底才甩向左边，贴着整排尖刺飞过去。
  • 03 闪光闸：先整个翻过来往上掉；激光一闪就转，冲过去它就在身后亮起。
  • 04 大回环：绕着尖刺块一直顺时针转满一圈，四道激光一道接一道。
  • 05 翻天：等激光灭了掉下去，甩过尖刺，撞墙后接着转 90°，往上掉进天花板上的门。

操作

  • ← Q 逆时针，→ E 顺时针，R 这一关重来
  • 手柄：摇杆横向或 L2 / R2，Options 重来
  • 演示中按任意方向键就接手自己玩；画面上方一直提示下一拍。

和游戏一致的规则

  • 玩家照 PlayerController：自己不会走，只往屏幕下方掉；贴着墙滑动会被卡住。
  • 尖刺是整格判定；激光照 LaserEmitter：一直照到墙，熄灭前闪 0.5 秒，发射器本身是实心的小块。
  • 门照 GoalDoor：碰到门那一格、并且门正立（20° 以内）才过关。
  • 镜头照 MazeCameraFit：对准迷宫中心，大小固定，转到任何角度都装得下。旋转速度默认 135°/s（游戏里的值）。
