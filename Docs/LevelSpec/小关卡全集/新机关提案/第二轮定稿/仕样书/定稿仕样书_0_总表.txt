====================================
六、通用规则（和 仕样书_0 一样，这里只提醒）
====================================

1. 矿坑、岩浆、天空的机关在关卡坐标里自己模拟（x 向右、y 向下，1 格 = 1 单位），每个 FixedUpdate 一步，dt = 0.02；显示按上一步和这一步插值。
   "重力方向" g = (sin θ, cos θ)，θ 是世界转角（顺时针为正）；"上" = -g。
2. 玩家判定用两个碰撞圆，半径 0.4，圆心在脚底往上 0.4（下圆）和 1.13（上圆）。死亡一律 player.Die()，原型里的死因文字不用做。
3. 飘字 feedback.Pop(key)，擦边 feedback.NearMiss(kind)，震屏 feedback.Shake(值)（迷宫场景也有 NearMissFeedback，Shake 一样能用）。新飘字见第七节。
4. 原型里只给演示用的东西不做（每拍提示、自动演示、标题卡、死因）。数值以仕样书为准，没写到的看原型代码。
5. 新贴图：Sprite、Pixels Per Unit 16、Filter Point、不压缩、不要 mipmap。
   矿坑、岩浆、天空的由 Build Small Levels 导入，pivot 读 json 的 sprites 表。
   迷宫的放 Assets/Resource/Art/Maze/Sprites/，pivot 照 素材/迷宫/Sprites/新精灵_pivot.json 手动设（归一化，左下为 0）。
   迷宫背景照 仕样书_8 的路径：Background、Exterior、Foreground 放进 Assets/Resource/Mode/Cave Tileset/ 对应文件夹，.meta 照 Maze_08 的设、用新 GUID。
6. 缩略图：素材/Menu/Thumbs/ 里的图复制到 Assets/Resource/Art/UI/Pixel/Menu/Thumbs/（thumb_Sky_03、thumb_Sky_04 覆盖原图），
   再跑 Tools/Gravity Game/UI/Apply Menu Presentation。
