第二轮定稿 仕样书 3：矿坑「炸药桶 + 裂岩」，新关 Mine_11 炸开（第二轮重做）

看效果：原型/第二轮_矿坑.html 选 1-A；设计图/设计图_Mine_11_炸开.png。
玩法：冲到隧道尽头、转回来往下掉；旁边竖井顶上的炸药桶同时往下砸，比人快得多，一落地 0.45 秒就炸。
它一落地就得马上逆时针拐进左边的侧洞躲开；炸完再顺时针转回竖井，从炸开的井底掉进门。在竖井里一直往下掉会被炸飞。

1. 数据（Mine_11）
   tnts [[x, y, 方向, 晃动秒数, 触发框]]：炸药桶（半径 0.45）。方向见第 4 条；晃动秒数可以省略，默认 0.2；触发框同松石（仕样书 1），可以省略。
   weak [[x0, y0, x1, y1]]：裂岩矩形，格子坐标，含 x0..x1-1、y0..y1-1。
   关卡级字段：tntG 炸药桶下落的重力倍数（默认 1）、tntFuse 落地后的引信秒数（默认 0 ＝ 落地就炸）、
   tntHit 落地多快算重摔（默认 7）、blastKill 爆炸致死半径（默认 2）。Mine_11 是 1.8、0.45、9、3.2。
   SmallLevelData 加 tnts、weak 和这四个数，Parse 读进来。
2. 素材：level_Mine_11.png（裂岩的格子在图里是空的，由裂岩贴片盖上）；Sprites/tnt_barrel、tnt_barrel_hot、weak_rock_0～3。
3. 裂岩：生成场景时建一张带 TilemapCollider2D 的 Tilemap（WeakRock），weak 里每格铺 weak_rock_((x+y)%4)。
   裂岩格在 SolidAt 里算实心；被炸掉的格子 SetTile(null) 并改成空；死了重来时全部铺回去。
4. 炸药桶（MineMechanisms，复用 Rock 的滚动和碰撞；参照原型 stepRocks、explode）
   松开：left / right 和松石一样（世界往那边斜过 25°）；down ＝ 世界摆正到 25° 以内（重力的 y 分量 > cos 25°）就松开。
     有触发框的，玩家下圆的圆心先进过框才开始看。松开后晃"晃动秒数"再开始掉。
     Mine_11 的桶挂在竖井顶上，触发框是隧道尽头 [12.5, 2, 15, 5]：玩家斜着世界冲到尽头，一转回来它就掉。
   下落：加速度 ＝ 重力 × tntG，速度上限 20（关卡没写 tntG 时还是松石的 15）。
   撞击：撞墙或地的法向速度 vn < -tntHit 才算重摔，否则只是弹。
     重摔时，tntFuse > 0：桶停在落点不再动，飘字 pop.tnt_fuse，震屏 0.3，桶顶一直冒火星，tntFuse 秒后爆炸；tntFuse = 0：当场爆炸。
   爆炸，以桶心为圆心：
     2.4 内的裂岩格全部炸掉（格子矩形到圆心的最近距离 < 2.4）；
     玩家任一碰撞圆的圆心到桶心的距离减 0.4 < blastKill 就死；< blastKill + 1.6 触发 NearMiss("boom")；
     距离 < 2.4 + 对方半径 的其他炸药桶 0.14 秒后跟着炸，松石直接碎；
     飘字 pop.boom，震屏 0.95，橙色闪屏，火花和碎石粒子，一圈 0.6 秒扩散的冲击波环（最大半径约 2.75）。
   提示：速度 > 5.6 时、还有点着以后，每 0.07 秒在 tnt_barrel 和 tnt_barrel_hot 之间切换。
   被滚动中的桶砸到（相对速度 > 2.5）和松石一样死。
5. LevelOrder：Mine_11 放在 Mine_10 后面。名字 level.Mine_11；缩略图 thumb_Mine_11.png。
6. 验证：Build Small Levels，ValidateGeneratedLevels 通过；Play Mine_11：顺时针冲到隧道尽头，转回来往下掉，桶在旁边竖井里砸下去，
   一落地就"滋——"；马上逆时针拐进左边侧洞，0.45 秒后井底的裂岩炸开；顺时针转回竖井、再转正，从洞里掉进门。
   在竖井里一直往下掉会被炸死。汇报 3 到 5 行，不写报告文件。
