仕样书 3：岩浆 Lava_01～04（封口、追击、晃开、冲门）

先读 仕样书_0_总览和通用规则.txt（坐标换算、擦边慢动作、镜头、生成器都在那里）。
原型页：原型/岩浆_原型.html；参照实现：原型/岩浆_原型代码.js（下面括号里是对应的函数名）。
数据：数据/lava_levels.json；图：素材/岩浆/level_Lava_0N.png（岩石、发光裂缝、喷口都画好了）。
本世界：PR = 0.4，G = 9.81，玩家下落上限 16，旋转 180°/s，擦边冷却 1.6 秒，摄像机背景 (38,18,15)，暗红暗角。

岩浆是粒子流体，只会烫死玩家，不推玩家、不挡路。四关的区别只在数据：
  Lava_01 封口：池子 + 天花板喷口（vent）；Lava_02 追击：一池冷却的岩浆，玩家走过 x > 8 就活了，流动阻力 ×0.9；
  Lava_03 晃开：一大池，靠转世界把它晃开；Lava_04 冲门：一池冷却的岩浆，玩家走过 x < 4.2 就活了。

====================================
一、格子
====================================

实心格 = 整张图先全是实心，carve 挖空，fill 填回；关卡外也算实心。岩浆只和这张格子表碰撞（不用 Physics2D）。

====================================
二、流体（lavaStep，照原型逐步移植，C# 用 float 就行）
====================================

常数：间距 SP 0.3，作用半径 H 0.62，压力 K 150，近压力 KN 250，内聚 COH 0.3，阻尼 DAMP 0.3，黏性 SIG 0.3、BETA 0.05，
贴墙摩擦 FRIC 0.1，粒子碰墙半径 RP 0.12，速度上限 VCAP 13，最多 1500 个粒子；流动阻力 c2 = 0.25 × dragMul（Lava_02 的 dragMul = 0.9，其余 1）。
静止密度 RHO0：间距 SP 的六角格子里，一个粒子周围 H 以内所有邻居的 (1 - d/H)² 之和（原型 RHO0 那段）。
每个粒子：位置、速度、组号 g、是否冷却（frozen）、是否带硬壳颜色（crust）。冷却的粒子不动，但别的粒子会被它挡住。
重力 (gx, gy) = G × (sin θ, cos θ)。每步 dt = 0.02：
1. 没冷却的粒子：v = (v + g × dt) / (1 + DAMP × dt)，再 v ×= 1 / (1 + c2 × |v| × dt)。冷却的 v = 0。
2. 黏性：每一对 i < j、距离 r < H（两个都冷却就跳过）：u = (vi - vj)·n（n 是 i 指向 j 的单位向量），u > 0 时
   I = dt × (1 - r/H) × (SIG × u + BETA × u²) × 0.5，没冷却的 i：vi -= I × n；没冷却的 j：vj += I × n。
3. 记下旧位置，没冷却的粒子 x += v × dt。
4. 双密度松弛：对每个没冷却的 i，邻居 j（r < H）：q = 1 - r/H，rho = Σq²，rhon = Σq³；
   P = K × (rho - RHO0)，P < 0 时 P ×= COH；Pn = KN × rhon；
   每个邻居 D = dt² × (P × q + Pn × q²) × 0.5：j 冷却时 j 不动，i 沿 -n 退 2D（代替 D）；否则 j 往 +n 挪 D，i 往 -n 退 D。最后 i 的位置加上累计的退量。
   （j 的位置当场就改，和原型一样。冷却粒子的 rho 记成 RHO0。）
5. 没冷却的粒子撞墙（lavaCollide）：和矿坑一样的圆碰格子（半径 RP，最多 3 次迭代），每次推出后再减掉"这一步沿墙切向走的距离 × FRIC"（贴墙摩擦）；
   位置限制在 [0.2, w - 0.2] × [0.2, h - 0.2]。速度 = (新位置 - 旧位置) / dt，超过 VCAP 按比例缩回。
6. 落单的小滴自己冷掉消失：每个粒子一个计时，冷却粒子为 0；rho < 0.3 时 += dt，否则清零；超过 0.6 秒删掉，原地冒一小团烟（大小 0.26，寿命 0.7 秒，往屏幕上飘）。
邻居查找用边长 H 的格子。

开局：直接用数据里每关的 lavaStart（原型里已经铺好池子、静置 90 步的状态：x、y、g、frozen、crust 数组），不用再静置。
模拟时机：预览时不动；正式开始以后一直走，玩家死后红光那 0.5 秒也继续流。

====================================
三、喷口（Lava_01，stepVent）
====================================

vent = { x 2.9, y 2, dx 0, dy 1, rate 22, max 150 }，只在玩家活着时出岩浆：
累计 += rate × dt；每满 1 个：k 依次取 0、1、2 循环，出生点 (x + (k - 1) × 0.24, y + 0.18)；
已经喷了 max 个、或者出生点 0.2 以内已经有粒子就跳过；否则加一个粒子，速度 (dx, dy) × 2.6，组号 0，不冷却。
crust = hash(made × 0.731, 3.3) > 0.7，made 是加过的粒子总数：开局 made = lavaStart.n，每加一个 +1（hash 见第六节）。

====================================
四、冷却的池子醒过来（Lava_02、Lava_04，checkWakes）
====================================

数据 wakes：[{ group, axis, op, value }]。玩家下面那个圆心（关卡坐标）第一次满足条件（例如 x > 8）时，这一组所有冷却粒子变成没冷却；
真有粒子被唤醒时：小字 pop.lava_wake，震屏 0.25。每组只醒一次。

====================================
五、判定（checkHazards）
====================================

每步对玩家两个圆心 c 分别数"没冷却"的粒子：
  touch = 距离 c 小于 PR + 0.08 的个数（两个圆心取大）；
  near = 最近粒子距离 < PR + 0.75 时，距离 c 小于 PR + 0.75 的个数（两个圆心取大）。
1. touch ≥ 4：死亡。
2. 1 ≤ touch ≤ 3：只是滋滋响，玩家身上冒 4 小团烟（最快 0.15 秒一次），不死。
3. near ≥ 2：擦边 "lava"。

====================================
六、显示（buildLava）
====================================

1. 一张 (w × 8) × (h × 8) 的贴图（1 格 8 个像素），Point，左上角对齐 Level 原点，每个物理步重画一次。
2. 每个粒子在半径 0.4 格内往三张缓冲里加权 w = (1 - d²/0.4²)²：总量 f；crust 粒子另加到 cr；冷却粒子另加到 fr。
3. 每个像素：f < 0.42 透明。否则 e = f - 0.42，k = cr / f：
   冷却为主（fr > 0.5 × f）：e < 0.14 用 (150,64,34)；否则 hash 亮缝 > 0.9 用 (196,76,26)；否则 k > 0.42 用 (52,20,14)；否则 (74,28,18)。
     亮缝 hash：hx = 像素x >> 1，hy = 像素y >> 1，hash(hx × 0.37 + hy × 1.31, hy × 0.53 - hx × 0.21)。
   流动的：e < 0.14 边缘 (255,228,150)；k > 0.42 时 e < 0.6 用 (150,46,22)、否则 (92,26,14)；其余 e < 0.45 用 (255,156,48)、否则 (238,98,30)。
     最后一种颜色上加闪点：hash(像素x >> 1, 像素y + floor(时间 × 6) × 3) > 0.93 时三个通道各 +30。
   hash(x, y) = frac(sin(x × 127.1 + y × 311.7) × 43758.5453)。
4. 辉光：把这张图缩到 1/4 和 1/16（双线性），叠加混合画在岩浆下面，透明度 1/16 那张 0.5、1/4 那张 0.35。
5. 顺序：整关图 → 门 → 辉光 → 岩浆 → 粒子 → 玩家（岩浆会盖住门，原型就是这样）。
6. 火星：每步从随机的流动粒子冒 floor(粒子数 / 70 + 随机 0～1) 个，速度 = 屏幕上方 × (1～3) + 随机 ±0.5，寿命 0.5～1 秒，大小 0.07～0.12，
   受 0.25 倍重力；颜色前半段 #FFD27A、后半段 #FF8A3A。烟 #3A3030 半透明，往屏幕上飘。
