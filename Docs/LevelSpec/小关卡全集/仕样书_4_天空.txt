仕样书 4：天空 Sky_01～04（跷跷板、气球雷、散云、气球平台）

先读 仕样书_0_总览和通用规则.txt（坐标换算、擦边慢动作、镜头、生成器都在那里）。
原型页：原型/天空_原型.html；参照实现：原型/天空_原型代码.js（下面括号里是对应的函数名）。
数据：数据/sky_levels.json；图：素材/天空/level_Sky_0N.png（浮岛、垂根、刺木、跷跷板轴下的小云）、backdrop_Sky_0N.png（天空和云海）；贴图：素材/天空/Sprites/。
本世界：PR = 0.4，G = 9.81，玩家下落上限 11，旋转 180°/s，擦边冷却 1.4 秒，摄像机背景 (238,242,249)，镜头跟随 k = 6、大小按云海边界算（仕样书_0 第六节）。

====================================
一、通用
====================================

1. 实心格只有 isles 里的矩形；关卡外是空的（开阔天空）。
2. 背景：backdrop_Sky_0N.png 左上角放在关卡点 (bound.x0 - 6, bound.y0 - 6)（数据里 backdropMargin = 6），排在最底下，跟着世界转。再往外就是摄像机背景色（和云海同色）。
3. 会动、会托住玩家的东西（跷跷板的板、云、气球平台）：每个一个 Kinematic Rigidbody2D + BoxCollider2D（云和平台 2hx × 2hy，跷跷板 2hl × 2ht），Wall 层，放在 Level 下。
   位置和角度在关卡坐标里算好，每个物理步用 WorldRotator 下一步的姿态（NextPosition、NextAngle）换成世界姿态，再 MovePosition / MoveRotation（和 PivotPendulum 读世界下一步姿态的做法一样）。
4. "站在 X 上"= 玩家和 X 有脚下的接触（接触法线朝屏幕上方，y > 0.5）。离开时记下时刻 leftAt[X]，擦边要用。
5. 机关在正式开始以后才模拟（预览时不动），玩家死后红光期间继续动。
6. 显示顺序（低到高）：backdrop → 整关图 → 门 → 跷跷板 → 云 → 气球平台 → 气球雷 → 粒子 → 玩家。
7. 风线：玩家往屏幕下方的速度 > 6 时，每步 60% 机率在玩家下面那个圆心 ±4 格内随机加一条白色细条（关卡坐标里竖着的 0.06 × 0.6，跟世界转），
   以 4 格/秒往屏幕上方飘，寿命 0.4 秒，不透明度 0.5 × 剩余比例。

====================================
二、云海边界（四关都有，checkHazards）
====================================

数据 bound = { x0, y0, x1, y1 }。玩家每个圆心 c：m = min(c.x - x0, x1 - c.x, c.y - y0, y1 - c.y)。
死亡：m < 0（掉进云海）。擦边 "void"：m < 2.2 并且玩家往屏幕下方的速度 > 3。
m < 3 时出红色暗角（仕样书_0 第七节）。

====================================
三、Sky_01 跷跷板（stepSees）
====================================

数据 sees：{ px, py（轴）, hl（半长）, ht（半厚 0.16）, a0（初始角，度） }。贴图 seesaw_board_48（hl 2.4）、seesaw_board_52（hl 2.6）、seesaw_hub。
板的角度 = a0 + ang（关卡坐标顺时针为正），板中心就在轴上。每块板的状态：
1. 静止：玩家站上去 → side = (rx × g.y - ry × g.x ≥ 0) ? +1 : -1（(rx, ry) = 玩家下面那个圆心 - 轴；就是玩家所在那一侧往下翻）→ 压住，0.15 秒（震屏 0.05，板沿自己长边方向随机抖 ±0.03）。
2. 翻：先小字 pop.tip，av = 0；每步 av += side × 16 × dt，ang += av × dt；|ang| 到 82° 时卡在 side × 82°，av = 0，震屏 0.2，停 1.6 秒。
3. 回：ang 以 1.4 弧度/秒转回 0，回到 0 变静止，又可以再踩。
4. 显示：板贴图按角度转（Unity 里取负），轴贴图盖在板上面不转。轴下面的小云已经画在整关图里。

====================================
四、Sky_02 气球雷（stepMines）
====================================

数据 mines：[ax, ay, len]（锚点和绳长 0.9）。贴图 balloon_mine、balloon_mine_anchor。
1. 雷球开局在锚点正上方 (ax, ay - len)，速度 0。每步：v += -g × 16 × dt（永远往屏幕上方飘），v ×= (1 - 3.5 × dt)，位置 += v × dt；
   离锚点超过 len 就拉回到 len 的圆上，并去掉往外的径向速度。所以世界一转，整片雷都跟着摆。
2. 判定：d = |圆心 - 雷球| - PR - 0.42。死亡：d < -0.1（雷爆：火花 22 个 #FFB347，震屏 0.5，这颗雷消失，然后死亡）。擦边 "mine"：d < 1.15。
3. 显示：锚点小块在 (ax, ay)；绳子从锚点到雷球，宽 0.04，颜色 (70,60,70, 0.75)；雷球贴图以 0.6 弧度/秒自转。

====================================
五、Sky_03 散云（stepClouds）
====================================

数据 clouds：{ cx, cy, hx, hy }（不转的方块）。贴图 cloud_platform_0、cloud_platform_1（对应数据里第 0、1 朵）。
1. 实：玩家站上去 → 开始散：倒计时 1.0 秒，小字 pop.cloud_fade。散的过程中照样能站。
2. 倒计时到 0 → 没了：关掉碰撞、隐藏，冒 26 团白色小云；如果玩家离开这朵云还不到 0.45 秒 → 擦边 "cloud"。
3. 没了 3 秒后恢复成实的。
4. 显示：散的过程中透明度 = 0.4 + 0.6 × 剩余比例，并随机抖 ±0.04 × (1 - 剩余比例)。
数据 spikes：[x0, y0, x1, y1] 刺木（画在整关图里，没有碰撞）。判定：d = 圆心到矩形的距离 - PR；死亡 d < -0.05；擦边 "spike"：d < 0.75。（Sky_04 也有刺木，同样处理。）

====================================
六、Sky_04 气球平台（stepPlats）
====================================

数据 plats：{ cx, cy, hx, hy }（板是不转的方块）。贴图 balloon_platform_board、balloon_0～2。
气球的位置：up = -g，side = (g.y, -g.x)；三个气球 (o, h) = (-0.9, 2.4)、(0, 2.75)、(0.9, 2.35)（依次用 balloon_0、1、2），中心 = 板中心 + side × o + up × h，半径 0.55。
1. 等：板上下轻轻浮：cy = 数据 cy + sin(计时 × 2.2) × 0.06。玩家站上去 → 上升，小字 pop.balloon_up。
2. 上升：板中心每步 += up × 3.2 × dt（永远往屏幕上方走）。
   gap = 三个气球中心到所有刺木矩形的最近距离 - 0.55。
   0 ≤ gap < 0.45 并且（玩家站在板上或离开不到 0.5 秒）→ 擦边 "pop"。
   gap < 0 或者上升满 4 秒 → 爆：小字 pop.balloon_pop，震屏 0.3，粉色碎片 18 个；玩家离开不到 0.45 秒 → 擦边 "pop"。
3. 爆了以后板照样有碰撞，受重力往下掉（v += g × G × dt），出了云海边界 6 格以外就删掉。
4. 玩家站在上升中的板上时要被稳稳托着一起往上走（原型里是板每步往上挪把玩家顶起来，不给玩家速度）。
   PlayerController 的防推动会扣掉平台推玩家的位移，这里要放行：站在上升中的板上时，把板这一步的位移原样加到玩家位置上。
   跷跷板翻的时候板是离开玩家往下转的，不需要这样处理。
5. 显示：气球不跟世界转（永远在屏幕上方），爆了就不画；三根绳从板上 (o × 0.8, -hy)（板的关卡坐标偏移）连到各自气球中心，宽 0.04，颜色 (80,70,70, 0.8)。
