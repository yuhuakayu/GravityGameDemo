仕样书：以玩家为中心旋转，镜头刚好框住整个迷宫

本文件取代 Docs/LevelSpec/仕样书_以迷宫中心旋转.txt 里"旋转中心"和"镜头大小"的部分。

现在（上一版改完后）：世界绕 RotationCenter（迷宫中心）旋转，镜头停在迷宫中心，大小用 MazeCameraSettings 里每关存的值。
改成：旋转中心改回玩家；镜头一直跟着迷宫走，大小自动变化，刚好把整个迷宫框在画面里。

====================================
一、做法（只改这些，五个迷宫关卡）
====================================

1. 旋转中心改回玩家：MazeSceneBuilder 里 world.pivot = null（回到原来的自动模式），不再建 RotationCenter。
2. 镜头位置：FollowTarget2D.target = World 根物体。
   迷宫中心就是 World 的原点，世界绕玩家转时迷宫中心会移动，镜头跟着它走；smoothTime 改成 0.1 左右。
3. 镜头大小自动计算：新组件 MazeCameraFit 挂在 Main Camera 上，开始游戏后每帧计算：
   θ = World 当前角度；w、h = 迷宫的宽和高（格）
   框宽 = |w·cosθ| + |h·sinθ|
   框高 = |w·sinθ| + |h·cosθ|
   orthographicSize = max(框高 / 2, 框宽 / 2 / aspect) + 留边
   用 SmoothDamp 平滑（约 0.15 秒）。
4. 留边每关可调：MazeCameraSettings 里每关存的值改成"留边"（默认 0.5 格，范围 0～4），以前存的镜头大小不用保留；
   控制台「镜头」区的滑条改成「镜头留边」，「保存为本关默认」按钮照旧。
5. 迷宫关卡里扳机缩放不再改镜头大小（避免和自动框选打架），浏览模式里照旧。
6. 外圈贴图按现在的 20 继续铺，不用改。

====================================
二、验证和汇报（只做这些）
====================================

1. 编译无错误，五个迷宫关卡重新生成。
2. Maze_01 进 Play：
   转动时以玩家为中心，玩家不会被墙扫到；
   整个迷宫一直刚好在画面里，转到 45° 也不超出画面；
   玩家下落时镜头不动；
   拖「镜头留边」马上变化，保存后重开本关仍然生效；
   重力锁出口、落地动作、死亡都正常。
3. 汇报 3 到 5 行，不写报告文件。
