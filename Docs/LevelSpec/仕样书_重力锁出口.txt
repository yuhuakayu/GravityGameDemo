====================================
二、MazeSceneBuilder 要改的地方
====================================

1. 地图新字母（门装在哪一面）：
     D = 门在地上（原来的）
     U = 门在天花板上，倒挂（上面那格必须是 #）
     [ = 门在左边墙上（左边那格必须是 #）
     ] = 门在右边墙上（右边那格必须是 #）
   BuildScene 里原来 cell == 'D' 时调用 PlaceDoor(door, center)，改成这 4 个字母都调用 PlaceDoor(door, center, cell)。

2. PlaceDoor 加参数 cell：
   先设门的旋转 door.transform.localRotation = Quaternion.Euler(0, 0, z)，z：D 为 0，U 为 180，[ 为 -90，] 为 90。
   再用原来的算法求门图底边中点（旋转以后的位置），让它对齐到这一格靠墙那一边的中点：
     center + (Vector2)(Quaternion.Euler(0, 0, z) * Vector2.down)
   D 的结果和原来一样（center.y - 1）。没有 DoorVisual 的旧 Tilemap 分支保持原样，只支持 D。

3. 门放好以后调用 GravityLockDoorSetup.Apply(door)，放在把门的渲染顺序设成 2 以上那段代码之后。
   它会在 DoorVisual 上加 SortingGroup，所以门和玩家的前后关系跟原来一样。

4. 其他不动。装饰生成本来就跳过不是 . 和 # 的格子，新字母不用特殊处理。

====================================
三、效果说明（脚本里已经实现，调参用）
====================================

门正立时（门的朝上方向和屏幕朝上方向夹角不超过 20 度）解锁：表盘和门缝亮青色，玩家碰到门就过关（流程和原来一样）。
门歪着时锁住：表盘暗、门缝熄灭。玩家碰到时表盘闪红 1 秒，不过关；玩家还在门里时把世界转正，门马上打开。
解锁以后要歪到 23 度才重新锁上，避免在边缘来回闪。
指针是一个小钟摆，永远指向屏幕下方；世界转得快时会晃一下再停住。
天花板门要把世界翻过来 180 度才算正，墙上的门要转 90 度。
解锁角度：GoalDoor 的 unlockAngle（默认 20），relockMargin（默认 3）。运行时也可以在调试控制台「参数」页拖动。
