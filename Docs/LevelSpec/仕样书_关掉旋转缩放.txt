仕样书：关掉旋转时的镜头缩放

本文件取代 Docs/LevelSpec/仕样书_镜头框住整个迷宫.txt 第一节的第 3、4 条，其余照旧。
原因：镜头大小跟着旋转角度变，用手柄转起来会晕。

====================================
一、做法（只改这些）
====================================

1. MazeCameraFit：镜头大小不再跟着角度变，每关固定一个值，旋转时完全不缩放。
   默认值 = 转到任何角度都能装下整个迷宫的大小：
   R = sqrt(w² + h²) / 2 + 0.5
   orthographicSize = max(R, R / aspect)
   同时去掉"镜头追赶迷宫时临时放大"的保护（requiredSize），避免转动时出现细小缩放。
2. 旋转中心照旧是玩家，镜头位置照旧跟着迷宫中心走（FollowTarget2D，smoothTime 0.1）。
3. MazeCameraSettings 每关存的值改回"镜头大小"；值为 0 表示没存过，用上面的默认值。
4. 控制台「镜头」区：
   「镜头大小」滑条（4～20，实时生效）；
   「保存为本关默认」按钮照旧；
   加一个「恢复默认」按钮，清除本关保存的值，回到上面的默认值。

====================================
二、验证和汇报（只做这些）
====================================

1. 编译无错误。
2. Maze_01 进 Play：
   用手柄转动时镜头大小完全不变；
   用默认值时，转到 45° 迷宫仍然整个在画面里；
   滑条、保存、恢复默认都正常；换到 Maze_02 用它自己的值。
3. 汇报 3 到 5 行，不写报告文件。
