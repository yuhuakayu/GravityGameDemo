# 柱子防推动与夹死保护

已在 Stage1、Stage2 配置完成，默认开启。玩家保留 Dynamic 实体碰撞，速度由自身输入、冲刺和屏幕向下重力计算；运动几何只能阻挡或触发有限的位置修复，不继承平台速度。

## 使用

1. 运行 Stage1 / Stage2，开始游戏后旋转世界或接触原有两根柱子。
2. 按 `~`，打开「游戏参数」页的「旋转几何体 · 玩家防推动」。可切换防推动、修复向量、每步速度日志。关闭防推动可对比旧的物理推动行为。
3. 在「场景跳转」页进入 `Test_PillarCrush`，按 Enter 开始。橙色长柱以 **180°/秒**旋转，玩家初始位于扫过路径；A/D 移动、Space 跳跃。测试场景不消耗氧气，默认开启速度日志和修复向量。该场景已加入 Build Settings，因此新打包版本也能从调试台进入。
4. 修复向量需打开 Unity 的 Gizmos；日志在编辑器 Console 或构建的 Player.log 查看。调试台开关只影响本次运行，重开恢复场景配置。

现有两个正式关卡无需再拖拽组件。新关卡的玩家需配置 CrushGuard.playerCollider 和 worldGeometryMask；世界几何使用 Wall / Box 层。带独立 Composite 刚体、但应固定跟随世界的几何，应填入 WorldRotator.attachedGeometryBodies；独立运动柱子使用自己的 Kinematic 驱动，不填该数组。

## 参数与执行顺序

- 玩家 Rigidbody2D：Dynamic、Continuous、Interpolate、冻结 Z 旋转。
- PlayerController：antiPushEnabled 默认开启；logVelocityDelta 默认关闭（测试场景开启）。intendedVelocity 在每个 FixedUpdate 由自有状态生成，不从碰撞后的刚体速度续算。
- 自管理模式中 rb.gravityScale 在运行时为 0，原始重力倍率由控制器保存并手动积分。冲刺通过 SimulatedGravityScale 临时减弱重力、结束后恢复；关闭保护则交回 Unity 重力。
- WaitForFixedUpdate 后先移除解算器注入的速度，并限制几何带来的额外位移，再调用 CrushGuard。正常撞墙、落地仍可削减自身速度，沿接触法线投影。
- CrushGuard：maxDepenetrationPerStep=0.15、overlapIterations=3、crushFrameThreshold=10。所有迭代与抬出共享 **每步 0.15** 的总路程预算。仅写 rb.position，不写速度、不调用 MovePosition。
- 连续未脱离且修复方向反复反转时判定夹死。默认第 10 步判定，接下来沿重力反方向抬出；再持续 10 步失败时调用原 PlayerController.Die()。也可在 Inspector 选择 IgnoreCollision 或 Kill。临时忽略只针对当前碰撞对，分离、超时、禁用或关闭保护后恢复。
- 世界根节点和跟随的 Composite 刚体使用 Kinematic、Full Kinematic Contacts、Interpolate，通过 MovePosition / MoveRotation 驱动。默认 maxAngularSpeed=120°/秒、maxStepAngle=3°；Stage1 的 Wall 独立刚体已加入跟随数组，非等比缩放偏移已验证。

**关于大角度子步：** Unity 在一次物理模拟前多次调用 MoveRotation，只会使用最后的目标，不会产生中间碰撞解算。因此实现为每个真实 FixedUpdate 限制 `min(maxAngularSpeed × fixedDeltaTime, maxStepAngle)`，剩余角度留给后续真实物理步。默认 0.02 秒步长时，上限为 2.4°/步。速度输入积压限制为 0.25 秒，角度模式使用最新目标；暂停、预览、死亡和太阳脉冲会丢弃旧目标，恢复后不会补转。没有修改全局物理参数或手动模拟正式游戏场景。

## 验证结果

Unity 6000.1.3f1 编译通过。16 项玩家/冲刺检查、10 项世界旋转检查全部通过；使用 Play 模式中隔离的 PhysicsScene2D，同步逐步模拟并保留原始解算速度，测试调用的 Simulate 只作用于临时测试场景。

| 检查 | 结果 |
| --- | --- |
| 静止玩家受 180°/秒柱子扫击，正常重力 | 原始解算速度变化约 9.007；最终前后速度向量变化 **0.00856 ≤ 重力贡献 0.1635** |
| 关闭保护复现 | 单步保留的解算速度注入峰值约 **7.855 单位/秒** |
| 紧靠墙角受扫击 | 实际墙接触 8 帧，无额外速度增益，修复总长 ≤0.15（浮点误差除外） |
| 旋转柱顶、零输入零重力 | 最终速度保持 0，仅允许有限位置分离 |
| 平移平台 | 横向带动位移 0 |
| 左右穿透修复 | 修复方向正确，预算 ≤0.15；修复前后速度完全不变 |
| 静态落地、撞墙、15°斜坡行走 | 保留碰撞前合法移动，无悬空；斜坡保持接触并向前移动 |
| 自由落体 | 1 秒速度 -9.81，重力只积分一次 |
| 冲刺 | 只扣一次氧气；临时重力 2→0.2→2；撞墙停止、冷却正常 |
| 世界旋转 | 120°/秒限速、3°单步限制、最新目标覆盖与输入积压限制通过 |
| 根节点/Composite | 普通姿态与非等比缩放下跟随正确，无重复旋转 |
| 暂停、太阳脉冲、预览、禁用 | 旧目标清除，恢复后无补转 |

另外在实际测试场景验证默认夹死流程：第 10 次检测后进入抬出，第 20 次仍未脱离时死亡；原死亡过渡完成后，Test_PillarCrush 被重新加载，新玩家恢复、预览为 true、timeScale=0。后物理协程日志及调试台界面也已检查。

验收中的“速度变化 ≤ 重力贡献”针对静止玩家受扫击的场景；一般落地或撞墙会合法削减原有速度，总向量差可能大于重力贡献。报告同时保留原始速度、自有速度、最终速度与位置修复数据，不把这种制动误报为外部推动。
