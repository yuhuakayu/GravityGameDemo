UI 仕样书：选关界面（像素简约风）

参考图：Docs/UISpec/images/ref_levelselect.png
总体风格、配色、字体、Canvas 设置沿用 Docs/UISpec/UI仕样书_像素简约风.txt。

====================================
一、素材（已准备好）
====================================

Assets/Resource/Art/UI/Pixel/Level/
  ui_card_normal.png      可选关卡卡片（已通关、未通关都用这张）
  ui_card_selected.png    当前选中的卡片（粉色边框，图里已经上浮 3 像素）
  ui_card_locked.png      未解锁卡片（整体变暗）
  ui_thumb_placeholder.png   缩略图占位（48x34 像素），以后换成每关截图
  ui_icon_lock.png        锁头，放在未解锁卡片的缩略图中央
  ui_icon_check.png       已通关的青色勾，放在缩略图右上角
  ui_title_select_level.png  标题图片
返回按钮用 Assets/Resource/Art/UI/Pixel/ui_button_normal.png / ui_button_selected.png。

卡片尺寸 62x84 像素，缩略图区域在卡片内左上 (7,9) 起、48x34（选中卡片整体上移 3 像素）。

====================================
二、布局
====================================

1. 背景：和主菜单同样的深色渐变，去掉原来的城堡背景。
2. 标题图片居中偏上。
3. 卡片横向一排居中，间距约 4 像素（美术像素）。关卡多了就左右滚动，选中的卡片保持在可视范围内。
4. 卡片下半部分文字（TextMeshPro）：
   编号 01、02……  Bold，约 34，浅色 #CFCCE3
   关卡名          Regular，约 17，浅色
   状态文字        Regular，约 12：已通关写 CLEARED（青色 #3FD6E0）；未解锁写 LOCKED，关卡名显示 ???（文字颜色 #5A587C）
5. 左下角返回按钮。
6. 底部居中操作提示：◀ ▶ Select   × Start   ○ Back，Regular 约 18，颜色 #9694BA。

====================================
三、行为
====================================

1. 选中状态换卡片图片（normal / selected），不要再用原来的黄色大框。
2. 未解锁的卡片可以被选中查看，但按确认不进入关卡。
3. 只换外观和布局，不改选关逻辑、解锁和存档。

====================================
四、验证和汇报（只做这些）
====================================

1. 编译无错误。
2. 进选关界面截一张图，对照参考图。
3. 汇报 3 到 5 行，不写报告文件。
