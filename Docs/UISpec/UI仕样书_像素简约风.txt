UI 仕样书：像素简约风（全套 UI 替换）

====================================
一、目标
====================================

把游戏里所有玩家可见的 UI 换成统一的像素简约风，参考图：
  Docs/UISpec/images/ref_menu.png       主菜单
  Docs/UISpec/images/ref_settings.png   设置页

风格要点：扁平、没有花纹；按钮、箭头、勾选框是像素画法；中文用平滑的衬线字体；当前选中项用粉色。

不包含：~ 调试控制台（IMGUI，保持原样）。

====================================
四、规则
====================================

1. Canvas Scaler：Scale With Screen Size，参考分辨率 1280x720，Match 0.5。
2. 按钮、面板用 Image Type = Sliced；不要拉伸成模糊，所有 UI 图片保持 Point 过滤。
3. 按钮文字：Bold，约 24；设置项名称：Bold，约 21；数值和分组名：Regular，约 18。
4. 手柄 / 键盘选中的按钮显示 ui_button_selected，其余显示 ui_button_normal。用 Selectable 的 Sprite Swap 实现。
5. 左右切换项到头时，对应箭头换成 _disabled 版本。
6. 只换外观和布局，不改菜单逻辑、按钮功能、存档和设置的读写。
7. 已有的自制手柄按键提示图标（扳机、摇杆提示）保留，不替换。

====================================
五、需要替换的界面
====================================

请先找出所有玩家可见的 UI（主菜单、设置、暂停、关卡预览提示和开始按钮、HUD、氧气条、过关 / 死亡相关界面等），全部按上面的规则换掉。
布局参考 ref_menu.png 和 ref_settings.png：按钮居中竖排，设置页是中间一列面板，分组名加虚线分隔。
