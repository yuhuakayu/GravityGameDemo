====================================
二、画布和单位
====================================

1. 新菜单用一个 Screen Space Overlay Canvas，CanvasScaler 参考分辨率 1920x1080，Match 0.5（不是 PixelUI 默认的 1280x720），这样本仕样书和原型里的数字可以直接用。
2. 坐标都是这个画布的像素，原点左上角、y 向下（和原型一样）。放到 RectTransform 时用左上角锚点，y 取负。
3. 所有图片 Point 过滤、不压缩。显示尺寸 = 图片像素 x 倍数，直接设 sizeDelta，不要 Set Native Size。
   倍数：背景色块 4，吊灯、链子、小房间、房间里的门 4，Logo 3，卡片、名牌、勾 3，小菱形 4（20x20），宝石当前 5、其他 3。
4. 字：用项目里现有的像素字体（Assets/Resource/Fonts 下的 NotoSerifSC ... UI Pixel 或 Pixel），整数倍、Point 采样，看起来要像原型那样一格一格的硬边；原型里是无衬线字只是因为浏览器里没有项目字体。日文缺字按现有字体的办法处理。
   字号：菜单项字高约 39 像素粗体；卡片编号约 45、关卡名约 36；名牌世界名约 48 粗体、英文小行约 24；提示行约 24；“Q ◀”“▶ E”约 36 粗体。
   字间距（美术像素）：菜单 2，名牌世界名 3，名牌英文 2，Q E 2，卡片编号和关卡名 1，提示行 1。
   菜单、提示行、Q E 的字有 1 格深色描边 (24,22,46)；天空画面的提示行和 Q E 用 (60,84,130)、不描边。提示行字色 (170,166,220)，Q E 字色 (200,196,240)。
5. 动画全部用 Time.unscaledDeltaTime。物理部分用固定 4 毫秒子步（原型 step / stepOnce），帧率低时也不能穿帮。
6. 角度：原型是画布坐标（y 向下，正角 = 顺时针）。放到 Unity 时位置的 y 取负，rotation.z = -角度。
   原型里卡片和名牌是 x = 挂点x - sin(角) x 长，吊灯是 x = 挂点x + sin(角) x 长，两者正方向相反，照抄即可，不然晃的方向会反。

====================================
四、背景色块
====================================

1. 一张 480x270 的 RenderTexture（Point），每帧用一个 shader Blit 生成，RawImage 铺满全屏（1 格 = 4 像素）。最多 256 个色块（天空的云会越积越多，换世界过渡时两套一起画）。
2. 两层场：后层 A、前层 B。每个色块（中心 x、y，半径 r，权重 w，单位都是 480x270 的格）对每个格子中心的贡献：
   R = 1.4142 x r，距离 d < R 时加 w x (1 - d²/R²)²。
   颜色：B > 0.25 用 front；否则 A > 0.25 用 back；否则 base。
3. 色块 = json 里的 masses（随时间慢慢变形，公式在 json 的 note 里，L 0 是后层、1 是前层）+ 运行时的 movers：
   迷宫：每 0.9 到 1.7 秒，在左右两侧（x 14 到 130 或 350 到 466）的 y = 19 长出一滴，0.9 秒长到半径 4 到 7，然后往下掉（加速度 60，最快 70 格/秒），y > 250 后 0.3 秒缩没。前层。
   矿坑：同迷宫，半径 3 到 4.5，从 y = 14，每 1.6 到 2.8 秒，加速度 160，最快 120。前层。
   岩浆：每 0.7 到 1.3 秒，在左右两侧（x 范围同迷宫）从 y = 256 冒一个泡（半径 5 到 10）；先长 0.9 秒（同时以 6 格/秒上移），再往上加速（加速度 40，最快 34 格/秒，左右轻摆 sin(2 x 年龄) x 6 格/秒），y < 70 后 0.3 秒缩没。前层。
   天空：每 3 到 6 秒从左边外飘进一朵云（4 个圆，原型 cloud 的 parts），往右 6 到 14 格/秒，出右边删掉。前层或后层随机。
4. 配色（base / back / front，RGB）：
   迷宫 (52,46,108) (68,62,138) (100,94,190)
   矿坑 (56,40,30) (74,52,36) (112,80,50)
   岩浆 (54,18,22) (86,28,30) (222,92,44)
   天空 (112,172,230) (146,196,240) (246,250,255)
   标题画面用迷宫这套。
5. 换世界：旧场景的色块权重 1 - k、新场景 k（场相加，形状会自然融合），颜色也按 k 插值；k 在 0.7 秒内从 0 到 1，用 easeInOutCubic。过渡期间两个场景的 movers 都继续更新。
6. 吊灯暖光也画在这个 shader 里：对每盏可见的灯，算格子到灯中心的距离平方 d²（格为单位），往暖色 (255,186,104) 混合：
   d² < 64f 混 0.26，否则 < 196f 混 0.15，否则 < 484f 混 0.08，否则 < 900f 混 0.04；再乘这盏灯的可见度。f 是灯的闪烁系数（第五节）。

====================================
五、吊灯
====================================

1. 4 盏，挂点 x = 176、330、1622、1772，y = -6。链长 L（挂点到灯顶）：标题 190、330、270、150；选关 96、150、120、74；收起 -170。
2. L 用弹簧追目标：v += (70 x (目标 - L) - 9 x v) x dt。换目标时按第 0、3、1、2 盏的顺序每盏晚 0.12 秒（开机再整体晚 1.0 秒，从选关回标题晚 0.3 秒），并随机给一点摆动。
3. 摆动是单摆：ω² = 1000 / max(80, L + 60)，阻尼 0.55，加一点微风 sin(0.6t + 相位) x 0.06。小房间开始转、卡片被绳子接住、房间落地时给一点角速度（原型 kick）。
4. 画法：链子从挂点沿摆角方向画到 L，每隔 12 像素放一节，深浅交替（chain_dark 画成 4x12、chain_light 画成 8x12，各自居中），节本身不旋转，位置对齐 4 像素格；
   灯身 lamp 图 44x56，灯身中心在链长 L + 28 处，跟着摆角转。
   火苗：n = sin(13t + ph) x sin(7.3t + 2ph)，n > 0.35 用 lamp_1，n < -0.35 用 lamp_2，否则 lamp_0；闪烁系数 f = 1 + 0.08n。可见度 = clamp((L + 40) / 60, 0, 1)。
5. 标题、迷宫、矿坑放下灯；岩浆、天空收起。

7. 物理（原型 Dangle）：卡片和名牌都是挂在绳上的单摆。
   绳子是单向的硬弹簧，只拉不推：伸长时加速度 = 3600 - 1500 x 伸长 - 26 x 速度；没拉紧时只有重力，掉进来时速度上限 1700。
   摆角：角加速度 = -(3600 / Lp) x sin(角) - 3.0 x 角速度，Lp = 绳长 + 卡片高 / 2。
   每张卡片有一点微风：角速度 += sin(0.9t + 序号 x 1.7) x 0.3 x dt。
   掉进来：从自己的位置往上 (挂点 y + 40 + 300 + 随机 0 到 120) 开始掉；下排先掉，上排晚 0.2 秒，同排每列晚 0.06 秒；被绳子接住时随机给 ±0.75 的角速度并震屏 1.2。
   名牌：挂点 (960,-20)，绳长 64，高 102，从上方 380 掉下来（晚 0.3 秒），接住时震屏 2。
   换选中：旧卡片角速度 -= 0.9 x 方向，新卡片随机 ±0.8。
8. 进选关：标题离场，背景换到默认世界的配色（见本条最后），吊灯按世界放下或收起，名牌和卡片掉进来（卡片从 0.45 秒开始）。期间 1.1 秒不接受输入。
   默认选中：第一个没通关的关卡所在的世界和那一关（都通关了就迷宫第 1 关）。
9. 换世界（Q/E、PageUp/PageDown、LB/RB；或者左右选到头）：旧卡片松开绳子往外飞（横向随机 ±150 再往换世界的反方向偏 120，向上 60 到 220，随机旋转）掉出屏幕；名牌翻面（0.45 秒，scaleY = cos(π x 进度)，过一半时换成新世界）并晃一下；背景按第四节第 5 条换色；吊灯按世界放下或收起；新卡片 0.28 秒后开始掉进来。往右换过去选中新世界的第 1 张，往左换过去选中第 4 张。期间 0.75 秒不接受输入。
10. 进关：选中卡片的绳子断开，卡片带旋转掉下去（初速向下 120，随机 ±1.5 角速度），断掉的绳头回弹 0.4 秒；其他卡片晃一下（随机 ±1.25）；震屏 4。0.45 秒后照现在的做法设置 GameFlowState.HasEnteredGame = true 并调用 SceneTransition.Instance.LoadScene(场景名)。
11. 返回标题（Esc 等）：卡片全部松开掉出（横向随机 ±120，向上 80 到 280，随机 ±1 角速度），名牌以 (0,-150) 松开、随机 ±0.4 角速度，背景回迷宫，吊灯回标题长度，标题按第六节第 5 条进场。期间 1.2 秒不接受输入。
12. 震屏：整个菜单根节点随机偏移 ±震屏值（取整），每秒衰减 exp(-10t)。

====================================
八、输入
====================================

1. 标题：上下选择，到头循环（键盘方向键 / W S，手柄十字键 / 左摇杆，摇杆过 0.6 算一次）；确认 Enter / Space / Z / 手柄 South；鼠标移上去选中，点击确认。
2. 选关：左右按序号走（第一排最后一张往右是第二排第一张），只有第一张往左、最后一张往右时换世界；上下跳一排（同一列，没有就不动）；Q E、PageUp PageDown、手柄 LB RB 换世界；确认进关；Esc / Backspace / X / 手柄 East 返回标题；
   鼠标移到卡片上选中，点卡片直接进关，点 “Q ◀” “▶ E” 换世界，点底部提示行返回。
3. 转场期间不接受输入（原型 busy），同时沿用现有的 MenuInputBlocked（控制台、SceneTransition）。
4. 标题四项的作用：
   开始游戏：标题离场 0.5 秒后，设置 GameFlowState.HasEnteredGame = true 并用 SceneTransition.Instance.LoadScene 进入第一个没通关的关卡（都通关了就 Maze_01）。
   选择关卡：进选关（第七节第 8 条）。
   设置：打开现有的 Options 面板（新菜单先隐藏，Options 关掉后回到标题，标题重新进场）。
   退出：Application.Quit()。

====================================

十一、小粒子（少量，用对象池）
====================================

都是 4x4 的平涂小方块，位置对齐 4 像素格，最亮时透明度 0.8，淡入 0.4 秒、淡出 0.6 秒：
  吊灯火星：可见度 > 0.5 的灯，平均每秒约 0.9 个，在灯身中心往上 10 像素处出现，横向 ±6、上升 14 到 30 像素/秒，暖色 (255,186,104)，活 1.2 到 2.2 秒。
  标题和迷宫：浮尘 (170,166,236)，每秒约 3 个，随机位置，缓慢上飘，活 3 到 5 秒。
  矿坑：灰尘 (220,180,130)，每秒约 4 个，随机位置，慢慢四处飘（横向 ±8、纵向 ±3 像素/秒），活 3 到 5 秒。
  岩浆：火星，每秒约 7 个，从底部 120 像素内往上 40 到 90 像素/秒，颜色 (255,190,90) 或 (255,120,50)，活 2 到 4 秒。天空：不加。
同屏最多 40 个。
