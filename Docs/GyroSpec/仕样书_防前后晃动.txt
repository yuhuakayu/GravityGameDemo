仕样书：防前后晃动（只认方向盘式的竖向转动）

本文件补充 Docs/GyroSpec/仕样书_陀螺仪方向盘与调试控制台.txt 第 2 节，其余照旧。

====================================
一、现象和原因
====================================

现象：竖握手柄前后晃动时，世界也会跟着转；晃完再转方向盘，有时方向是反的。

原因（已用模拟数据确认）：
1. 方向盘轴的提取本身没问题，纯前后摆输出就是 0。
   但人手前后晃时总会顺带一点左右歪（约 5%～15%）。速度模式灵敏度很高（约 34°/s 就满输出，死区只有 1°/s），
   这一点漏进来，正常力度晃 4 秒，世界会被带着转 10°～110°。
2. SteeringExtractor.Extract 里"previousSpeed × candidateSpeed < 0 就翻转轴"的规则：
   前后晃时这两个投影几乎只有噪声，轴会被随机翻转。翻到反面后再转方向盘，方向整个反过来
   （模拟中晃一次后约 45% 的情况方向反了）。

====================================
二、做法（只改这些）
====================================

1. 偏轴过滤：GyroProcessor.ProcessSample 里，在 Extract 之后做（实机和 CSV 回放走同一条路）
   ω = 校准后的陀螺仪向量，s = LastSteering.AngularSpeed（方向盘分量）
   偏轴速度 off = sqrt(max(0, |ω|² − s²))
   纯度 p = |s| / |ω|；|ω| < 0.001 时 p = 1
   如果 off > 偏轴触发 且 p < 纯度下限：开始（或刷新）"晃动保持"计时 = 晃动保持时间
   权重 w：保持计时 > 0 时 w = 0；否则 w = clamp01((p − 纯度下限) / (纯度上限 − 纯度下限))
   计时按 sample.DeltaTime 递减；Reset 和 Disconnect 时清零。
   新增 GatedSpeed = s × w（关闭防前后晃动时 GatedSpeed = s）。
   改用 GatedSpeed 的地方只有两处：
     GyroProcessor 自己的 _stickMapper.Map
     GyroRuntime.ProcessSensorSample 里的 _mapper.Map
   不改：LastSteering、IntegratedWheelDegrees、控制台曲线（继续显示原始值，方便对比）。
   角度模式：w < 0.5，或 |加速度长度 − 1| > 0.15（单位 g，加速度长度为 0 表示没有数据，不做这项判断）时，
   这个样本不调用 AngleMapper.Evaluate，世界停在原角度；之后照常跟随。关闭防前后晃动时不做这一步。

2. 修正轴被随机翻转：SteeringExtractor.Extract
   上面那条按投影正负号翻转的规则，只在"手柄确实在自身 Y-Z 平面里转动"时执行：
   |ω| ≥ 20°/s 且 sqrt(ω.y² + ω.z²) ≥ 0.5 × |ω|
   不满足时只做几何连续：dot(candidate, _lastAxis) < 0 就 candidate = −candidate，不改 _crossedDegeneracy。
   其他逻辑（奇异锥、SetInitialAxis、Angle 计算）不变。这一条不受开关影响，一直生效。
   说明：前后晃是绕 X 轴转，不会再触发翻轴；"斜握连续转 360° 不反向"等现有用例照常通过（已模拟确认）。

3. GyroSettings 新增字段（"保存参数"时一起写入，旧存档读进来用默认值）：
   shakeReject = true          启用防前后晃动
   purityLow = 0.5             纯度下限，范围 0.2～0.9
   purityHigh = 0.8            纯度上限，范围 purityLow + 0.05 ～ 1
   shakeHoldTime = 0.12        晃动保持时间（秒），范围 0～0.3
   offAxisTrigger = 30         偏轴触发（°/s），范围 5～100
   Sanitize 里按上面范围钳制。

4. 控制台「陀螺仪」页加一个「防前后晃动」小框：开关 + 上面 4 个滑条，实时生效。
   读数区加一行：纯度 0.00 · 权重 0.00 · 晃动保持中（只在保持时显示后半句）。

====================================
三、验证和汇报（只做这些）
====================================

1. 编译无错误；现有 Gyro EditMode 测试全部通过（T4 测的是提取器本身，不用改）。
2. 只加 1 个短测试：竖握，前后摆 ±25°、2.5 Hz，带 12% 左右歪，持续 2 秒，
   处理器积分换算的世界旋转 < 1°；紧接着做一次纯方向盘转动，输出符号和没晃过时一样。
3. 实机 Maze_01：
   竖握前后晃 5 秒，世界基本不动；
   正常转方向盘，手感和以前一样；
   晃完马上转方向盘，方向正确（试 5 次）；
   切到角度模式再检查一次前后晃。
4. 汇报 3 到 5 行，不写报告文件。
