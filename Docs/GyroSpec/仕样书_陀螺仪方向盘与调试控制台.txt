0.2 项目背景
    Unity 2D 横版游戏。世界会旋转，玩家始终受到"向下"的重力。
    现在世界旋转是靠 Steam Input 的"陀螺仪转摇杆视角"把手柄陀螺仪变成右摇杆 X 输入，游戏再读右摇杆来转世界。
    已有：玩家控制器、地面/墙壁检测、关卡预览模式、死亡与场景过渡流程、太阳脉冲（脉冲期间重力控制器失效，锁定重力方向）。
    玩家使用 DualSense（DS5）手柄，USB 和蓝牙都要支持。

0.3 本次目标
    1）不依赖 Steam Input，游戏自己读取 DS5 陀螺仪，做出和 Steam 同款的旋转手感。
    2）只有"像方向盘一样"的转动才会让世界旋转，手柄前后摆动、左右甩动都不会触发。
    3）做一个按 ~ 打开的调试控制台，统一放场景跳转、陀螺仪参数、游戏参数、性能信息。
    4）必须做可靠性验证，并交一份测试报告。

0.4 工作规则
    先阅读现有代码，找到：世界旋转的代码、读取右摇杆的地方、太阳脉冲逻辑、关卡预览模式、场景过渡。
    在现有结构上扩展，不要重写已有系统。
    完成后列出：新增/修改的文件、需要在 Unity 里手动设置的地方、测试结果。

1. 陀螺仪读取（JoyShockLibrary）
====================================================================

1.1 Unity 自带 Input System 读不到 DualSense 陀螺仪，使用 JoyShockLibrary（简称 JSL，MIT 协议）。
    下载地址：https://github.com/JibbSmart/JoyShockLibrary/releases （使用支持 DualSense 的 3.x 版本）
    放置位置：Assets/Plugins/JoyShockLibrary/x86_64/JoyShockLibrary.dll（Windows x64）
    如果你无法联网下载，请在报告里写明，让开发者手动放入 DLL。
    P/Invoke 声明请以下载到的版本的 JoyShockLibrary.h 为准，不要凭记忆写函数签名。

1.2 连接
    游戏启动时连接设备（JslConnectDevices）。
    没有设备时，每 2 秒重试一次。连接操作可能会卡顿，请放在后台线程执行，不要卡主线程。
    手柄拔线/蓝牙断开：输出立即归零（最迟 50ms），不能报错；重新连接后自动恢复。
    游戏退出时断开所有设备（JslDisconnectAndDisposeAll）。

1.3 数据和时间
    使用 JSL 的回调（callback）接收每一个传感器样本。回调里带有 deltaTime，用它做时间计算。
    如果当前版本回调没有 deltaTime，就在回调线程里用 System.Diagnostics.Stopwatch 自己打时间戳。
    绝对不能用 Time.deltaTime 积分陀螺仪（游戏不锁帧，可跑到 600fps 以上，会导致不同电脑手感不同）。
    回调在其他线程，样本写入线程安全的队列（加锁或 ConcurrentQueue），主线程每帧取出处理。
    每个样本包含：deltaTime、陀螺仪三轴（度/秒）、加速度三轴、重力方向（优先用 JSL 的 motion state 融合后的重力向量）。

1.4 输入来源（控制台可选）
    陀螺仪（默认）：用 DS5 陀螺仪。
    右摇杆：不用陀螺仪，用右摇杆 X（给没有陀螺仪的手柄，如 Xbox 手柄）。
    两者叠加：两个都生效，结果相加后限制在 -1 到 1。
    自动回退：选"陀螺仪"但没检测到陀螺仪设备时，自动改用右摇杆，并在控制台显示"已回退到右摇杆"。
    不再读取 Steam Input 生成的旋转输入。测试时请在 Steam 里对本游戏关闭 Steam Input。

1.5 右触控板（喷气背包键）
    优先用 Unity Input System 的 DualSense touchpadButton 读取。
    如果读不到，改用 JSL 按键状态里的触控板按下位。
    重要：JSL 连接后（尤其蓝牙）可能会改变 DS5 的报告模式，导致 Unity 读到的按键异常。
    必须实测：JSL 连接后，Unity 里所有按键、摇杆是否仍然正常。若不正常，改为全部按键从 JSL 读取，并在报告里说明。

2. 方向盘轴的提取（核心）
====================================================================

2.1 定义
    "方向盘转动" = 手柄绕着"水平、指向屏幕"的那根轴转动。
    不管玩家是平握、竖握还是斜着握，都按这个定义计算。
    前后摆动（俯仰）和左右甩（偏航）都必须被过滤掉，输出为 0。

2.2 计算方法（在手柄本地坐标系里）
    g = 重力方向（单位向量，来自 JSL 融合后的重力）
    X = 手柄的左右轴（两个握把连线方向，本地坐标固定为 (1,0,0)，以 JSL 坐标定义为准）
    方向盘轴 F = normalize( cross(g, X) )
    方向盘角速度 ωs = dot(ω, F)     ω 为校准后的陀螺仪角速度
    方向盘角度 θ = atan2( dot(X, -g), 长度(X 在水平面上的投影) )   用于角度模式

    说明：绕 X 轴转（前后摆）时 ω 平行于 X，dot 为 0；绕重力轴转（左右甩）时 ω 平行于 g，dot 也为 0。
    平握时 F 等于手柄前后轴（即 roll），竖握时 F 等于手柄面板法线，斜握时自动取中间。

2.3 特殊情况
    当 X 几乎平行于重力（|dot(X, g)| > 0.95，即手柄侧立到接近 90°）时 cross 会退化，
    此时沿用上一个有效的 F，不能产生 NaN 或跳变。
    符号：顺时针转方向盘为正，世界顺时针旋转。用真机确认方向，控制台有"反转方向"开关。

2.4 代码要求
    这部分写成纯 C# 类（SteeringExtractor），不依赖 MonoBehaviour，只允许用 Vector3 / Mathf，方便写 EditMode 单元测试。

3. 两种控制模式（控制台勾选哪个就用哪个）
====================================================================

3.1 模式 A：速度模式（复刻 Steam 陀螺仪转摇杆）
    输出一个虚拟"右摇杆 X"值（-1 到 1），接到现有代码读取右摇杆旋转的地方，下游旋转逻辑保持不变。
    每个样本的处理顺序：
      1）速度 = |ωs|（原始度/秒）
      2）小于速度死区 → 输出 0
      3）乘以灵敏度
      4）精确速度 > 0 且速度低于精确速度时：速度 = 速度 × (速度 / 精确速度)
      5）t = clamp((速度 - 最低输入速度) / (最高输入速度 - 最低输入速度), 0, 1)
      6）t = t 的"输出曲线"次方（1 = 线性，小于 1 更剧烈，大于 1 更缓和）
      7）输出 = 输出最小值 + (输出最大值 - 输出最小值) × t，带上 ωs 的正负号
      8）反转方向开关
    帧处理：本帧所有样本的输出按各自 deltaTime 加权平均，作为本帧摇杆值。
    本帧没有新样本时，沿用上一帧的值，最多保持 20ms，超过则归零。
    说明：Steam 内部公式没有公开，这是近似复刻，手感以真机调参为准。

    默认值（来自截图 steam_03 到 steam_06）：
      灵敏度 5.25x
      最低输入速度 0°/s
      最高输入速度 180°/s
      输出最小值 7.1%
      输出最大值 100%
      输出曲线 1
      速度死区 1°/s
      精确速度 0°/s
      反转方向 关
      加速、动量、角度补齐：Steam 里都是关，本次不实现。
      垂直/水平混合器、反转 Y、环形/边缘锁定、旋转输出：只取方向盘一个轴时没有意义，不实现。

3.2 模式 B：角度模式（真方向盘）
    手柄倾斜多少度，世界就转到对应角度。
    世界目标角度 = (方向盘角度 θ - 回正基准) × 角度倍率
    参数：
      角度倍率 默认 1.0（范围 0.5 到 4.0）
      平滑时间 默认 0.05 秒（0 = 不平滑）
      角度死区 默认 1°（回正附近的小晃动不转）
    回正：控制台按钮 + 手柄按键（默认 L3 按下，可在控制台改），把当前方向盘角度设为基准。
    需要给现有世界旋转代码加一个"设置目标角度"的入口。如果现有代码只支持速度，就新增，不要破坏模式 A。

3.3 切换模式时不能让世界跳变：切到 B 时，自动把基准设成"当前方向盘角度对应当前世界角度"。

====================================================================
4. 校准（防零漂）
====================================================================

4.1 开局自动校准：检测到手柄静止 1 秒（陀螺仪各轴变化很小），取平均值作为零点偏移。
4.2 持续校准：游戏中手柄静止超过 2 秒时，缓慢更新零点偏移。
4.3 手动校准：控制台按钮，提示"请把手柄平放静止 3 秒"，显示进度，完成后显示新的偏移值。
4.4 JSL 有自带的校准功能时可以使用，但以上三种行为必须满足。

====================================================================
5. 和现有系统的配合
====================================================================

5.1 太阳脉冲期间（重力控制器失效）：模式 A 输出 0；模式 B 世界角度保持不动。
    脉冲结束时，模式 B 自动重新设定基准，保证世界不会一下子跳到手柄当前角度。
5.2 关卡预览模式、死亡过渡、控制台暂停时：不旋转世界。
5.3 预览模式里用陀螺仪平移镜头不在本次范围内。

    当前场景不可用的分页，显示"（此 Tab 在当前场景不可用）"，参考 console_ref_02。

    列出 Build Settings 中的所有场景：序号、场景名、路径、Jump 按钮。
    顶部搜索框，按名字过滤。
    显示当前场景名。

7.4 分页二：陀螺仪
    设备状态：手柄型号、连接方式（USB/蓝牙）、实际采样率（每秒样本数）、当前输入来源、是否已回退到右摇杆、校准状态。

    实时显示：
      原始陀螺仪三轴曲线（最近 5 秒）

    验证工具（见第 8 节）：录制开始/停止、录制文件列表与回放、漂移测试（5 分钟）、帧率一致性测试。

    内存：GC.GetTotalMemory、Profiler 总分配、总保留、Mono 已用
    运行环境：当前场景、运行时长、targetFrameRate、vSyncCount、屏幕分辨率和刷新率
    陀螺仪线程：回调是否在运行、队列里积压的样本数

8. 可靠性验证（必须完成，并提交测试报告）
====================================================================

8.1 自动测试（Unity Test Framework，EditMode，用模拟数据测试第 2、3 节的纯 C# 类）
    T1 纯方向盘：绕方向盘轴 1 秒内转 90°。模式 A 输出符号正确且不为 0；模式 B 角度 = 90° ± 1°。
    T2 纯前后摆：绕 X 轴 60°/s 摆动 2 秒。输出绝对值 = 0（死区后）。
    T3 纯左右甩：绕重力轴 60°/s 转 2 秒。输出 = 0。
    T4 混合：方向盘 30°/s + 前后摆 100°/s 同时进行。方向盘分量和 T1 同速度的纯方向盘结果误差小于 2%。
    T5 握姿：平握、竖握、45° 斜握分别做相同的方向盘转动，结果互相误差小于 2%。
    T6 帧率一致：同一段数据按每帧 1/60、1/144、1/600 秒切分处理，最终世界角度误差小于 1%。
    T7 零漂：模拟 0.5°/s 固定偏移 + 随机噪声，静止状态。校准后模拟 5 分钟，累计旋转小于 2°。
    T8 断线：样本中途停止。输出在 50ms 内归零，不出异常。
    T9 退化姿势：X 接近平行重力。不出现 NaN，输出不跳变。
    T10 模式切换、脉冲结束：世界角度不跳变。

8.2 录制与回放（控制台里）
    录制真机样本（deltaTime、陀螺仪、加速度、重力）为 CSV：persistentDataPath/GyroRecordings/时间戳.csv
    回放时用录制数据代替实时输入，走完全相同的处理流程，方便改参数后对比。
    自动测试 T6 也可以使用录制文件。

8.3 控制台内置测试
    漂移测试：提示把手柄放桌上，计时 5 分钟，显示累计旋转角度，小于 2° 显示"通过"。
    帧率一致性测试：选择一段录制文件，按 60 / 144 / 不锁帧三种方式回放，显示三个结果和误差。

8.4 真机手动测试清单（写在报告里，由开发者执行并打勾）
    USB 连接：陀螺仪正常，采样率显示正常
    蓝牙连接：陀螺仪正常，采样率显示正常
    JSL 连接后 Unity 按键、摇杆、触控板仍然正常（USB 和蓝牙各测一次）
    用力前后摆 10 秒：世界累计旋转小于 3°
    用力左右甩 10 秒：世界累计旋转小于 3°
    平握、竖握各转一次方向盘：都能正常旋转
    模式 B 转 90°：世界约转 90° × 角度倍率
    拔线再插回：自动恢复，不报错
    太阳脉冲期间转手柄：世界不动；脉冲结束后不跳变
    参数保存后重启游戏：参数还在

8.5 测试报告内容
    自动测试结果（通过/失败 + 数值）、发现的问题和处理方式、需要开发者真机确认的项目。
