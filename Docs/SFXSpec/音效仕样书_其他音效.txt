音效仕样书：其他音效（世界旋转以外）

世界旋转音效见 Docs/SFXSpec/音效仕样书_世界旋转.txt。
风格基准：游戏内音效以世界旋转的上发条声（真实机械录音质感）为准。不要加入 8bit / 芯片音、尖锐电子音这类违和的声音。
素材都在 Assets/Resource/Audio/SFX/。落地声来源：BigSoundBank「Jumping on concrete 2」(ID 1836)；开门声来源：Pixabay（dragon-studio「door closed」382707）。下面没有文件的项目标为「未确认」，暂时保持现状，不要改。

====================================
一、已确认（替换 SfxManager 里对应的程序合成音效）
====================================

  用途                文件                        触发时机
  落地                sfx_land.wav                玩家落地（实录落地声）；音量按落地力度 0.4～1.0，音高每次随机 0.95～1.05
  重落地              sfx_land_heavy.wav          从高处落下时代替普通落地：落地速度超过 heavyLandSpeed（默认约等于下落 4 格的速度，Inspector 可调）
  撞墙                sfx_wall_bump.wav           玩家在空中撞到侧墙
  死亡（所有死因）    sfx_death_suffocate.wav     缺氧、尖刺、激光等所有死亡统一用这一个
  出口门低鸣（循环）  sfx_door_hum_loop.wav       门附近循环播放，距离越近越响（约 6 格外听不到）
  开门                sfx_door_open.wav           玩家碰到出口门、开门动画开始时播放一次（此时停止门低鸣）
  捡氧气瓶            sfx_oxygen_pickup.wav       拾取氧气瓶
  UI 光标移动         sfx_ui_move.wav             菜单 / 选关里切换选项
  UI 确认             sfx_ui_confirm.wav          确认、开始游戏、进入关卡
  UI 错误             sfx_ui_error.wav            选到未解锁关卡按确认等不能执行的操作
  UI 返回             sfx_ui_back.wav             返回、取消、关闭菜单
  过关                sfx_level_clear.wav         开门音效开始约 0.3 秒后播放一次（接在开门声后面），然后照常进入过关流程
  下落风声（循环）    sfx_fall_wind_loop.wav      玩家在空中时播放：下落速度越快越响（离地慢速时几乎听不到，接近最大下落速度时音量约 0.45），落地 0.1 秒内淡出
  激光嗡嗡（循环）    sfx_laser_hum_loop.wav      每个激光发射器一个，按距离变化，和门低鸣一样（约 5 格外听不到，最大音量约 0.3）；激光关闭时停止
  洞穴底噪（循环）    sfx_ambient_cave_loop.wav   关卡内一直循环，音量低（约 0.25）

说明：
  所有死因统一播放 sfx_death_suffocate.wav。死亡流程本身不变。
  循环音效在暂停、预览时停止或静音，死亡和过场时淡出。
  洞穴底噪、激光嗡嗡、下落风声不能太吵，文件本身已经调小，按上表音量接入，不要再放大。

====================================
二、不再使用（删除）
====================================

  脚步声、跳跃声（已经没有移动键）
  原来的齿轮咔嗒、旋转吱嘎循环声（由上发条音效取代）
  喷气背包相关音效（喷气背包已取消）
  开始旋转、转到极限、激光开启：不需要音效，原来有的删掉
  尖刺、激光各自的死亡音效（统一成上面的死亡音效）
  项目里的 sfx_rotate_limit.wav、sfx_death_spike.wav、sfx_death_laser.wav 不使用，不要接入

====================================
三、未确认（暂时保持现状）
====================================

  低氧警报、关卡开始
  这两个维持原样，不要改。
  另外这些现有音效也维持原样：摆板撞击、场景转场呼声、火把/蜡烛噼啪循环、UI 悬停。

====================================
四、验证和汇报（只做这些）
====================================

编译无错误；进 Stage1 试：落地、撞墙、尖刺死亡、捡氧气瓶、菜单移动/确认/返回、下落风声、过关都有新声音；Maze_03 靠近激光能听到嗡嗡声。汇报 3 到 5 行，不写报告文件。
汇报里另外列出：项目里还在用、但不在本文件和世界旋转仕样书里的音效（一行一个，写用途和触发位置）。
